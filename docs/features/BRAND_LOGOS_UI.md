# Feature: Vector Brand Logo System & Ergonomic Design

- **Domain:** Brand Identity & Accessible UI Tokens
- **Key Components:** \ModelLogo.tsx\, \Navbar.tsx\, \Footer.tsx\, \globals.css\
- **Capabilities:**
  1. Crisp, pixel-perfect official vector SVGs for OpenAI, Anthropic, Google DeepMind, Meta, Mistral, DeepSeek, xAI, Qwen, Cohere, Groq, Together AI, Fireworks AI, AWS, and Azure.
  2. Responsive size scales (\xs\, \sm\, \md\, \lg\, \xl\) optimized for high-DPI displays in light and dark mode.
  3. Floating pill navigation bar with top margin clearance and blur backdrop.
  4. Full-width container expansion (\max-w-[1600px]\) eliminating edge whitespace.
  5. Ergonomic typography scale (16.5px base) adhering to ADR 009.
