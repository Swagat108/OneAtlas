# Feature: Global Instant Command Palette (Cmd+K)

- **Domain:** Global Search & Keyboard Navigation
- **Routes:** \/api/search\
- **Key Components:** \CommandPalette.tsx\, \useSearch\, \search.service.ts\
- **Capabilities:**
  1. Global keyboard shortcut listener (\?K\ on macOS, \Ctrl+K\ on Windows/Linux).
  2. Multi-entity unified search across Models, AI Research Labs, and Cloud Providers.
  3. Integrated brand insignia icons next to each search result.
  4. Full keyboard and mouse navigation with instant routing.
